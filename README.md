# Curso de Python Básico

¡Bienvenidos al repositorio del **Curso de Python Básico**! En este curso aprenderás los fundamentos de Python y cómo usarlo para resolver problemas de programación de manera eficiente.

Este repositorio contiene materiales, ejemplos y ejercicios para ayudarte a dominar Python. Cada clase incluye ejemplos prácticos, ejercicios y recursos adicionales.

## Contenido del Curso

Este curso cubre los siguientes temas:

1. **Variables y Colecciones**
   - Tipos de datos básicos.
   - Listas, tuplas y diccionarios.
   
2. **Condicionales y Bucles**
   - Estructuras de control.
   - Bucles `for` y `while`.

3. **Funciones y Matplotlib**
   - Definición de funciones.
   - Introducción a la visualización de datos con Matplotlib.

4. **Pandas, Estadísticas y Gráficos**
   - Manejo de datos con Pandas.
   - Estadísticas básicas y visualización.

5. **Creación, Lectura y Escritura de Archivos**
   - Cómo trabajar con archivos en Python.
   - Leer y escribir en Excel y CSV.

6. **Introducción a la Programación Orientada a Objetos (POO)**
   - Conceptos fundamentales de la programación orientada a objetos.

7. **Geopandas y Manejo de Datos Geoespaciales**
   - Introducción a **Geopandas** y manejo de archivos geoespaciales.
